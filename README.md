# DDD: Modelagem Tatica e Patterns

Projeto do curso Full Cycle 3.0
DDD: Modelagem Tática e Patterns

## Stack

- Node.js (24.15.0)
- TypeScript
- TSLint
- Jest
- Sequelize
- SQLite
- SWC

## Como executar

1) Instale as dependencias:

```bash
npm install
```

2) Rode o TypeScript (checagem de tipos):

```bash
npm run tsc -- --noEmit
```

## Como rodar os testes

```bash
npm test
```
